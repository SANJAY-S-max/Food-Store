# Food Store 🍕🌮

Welcome to my **Food Store** project! 🎉 This repository holds my very first learning project in web development. I built this frontend layout from scratch as I take my first steps into building responsive and modern web interfaces.

## 🌟 About This Project
This is a landing page for a fictional Food Store. It was created purely as a learning exercise to understand the fundamentals of web page structure and styling. Building this helped me grasp how elements are placed, styled, and aligned to create a full webpage.

## 🛠️ Tech Stack
- **HTML5:** For creating the structure of the webpage.
- **Tailwind CSS:** Used for styling! Utilizing utility classes really sped up the design process.
- **CSS3:** For any custom styling that needed a little extra touch.

## 🚀 Getting Started

Since this is a simple static project, there are no complicated build steps!

1. Clone the repository:
   ```bash
   git clone https://github.com/SANJAY-S-max/Food-Store.git
   ```
2. Navigate into the folder:
   ```bash
   cd Food-Store
   ```
3. Open `index.html` in any web browser to view the site!
